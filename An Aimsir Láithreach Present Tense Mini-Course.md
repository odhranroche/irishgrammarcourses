## Course overview

Fifteen lessons of 5–10 minutes each take you from the first ending on a regular verb to asking why, talking about routines with *nuair a* and *má*, and using the impersonal form. Each lesson teaches one rule that B1 learners get wrong if it isn't drilled on its own, shows it in model sentences from the SNAS.ie TEG B1 learning materials, then drills it in sets of five until it is automatic.

The whole present tense rests on two ideas:

1. **The ending does the work, and the start of the verb stays still.** Add an ending that matches the root's last vowel and length: *glanann, cuireann* (one syllable), *ceannaíonn, éiríonn* (two syllables). "I" and "we" are built in: *glanaim, glanaimid*. There is no séimhiú in a statement: *ólann sí, fanann sé*.
2. **One family of little words serves every verb.** Regular and irregular verbs alike take *an* + urú to ask and *ní* + séimhiú to say no. Only *tá* (*níl, an bhfuil*) and *deir* (*ní deir*) step out of line.

|  | Little word | Example |
| --- | --- | --- |
| Question | *an* + urú | *An gcuireann tú?* · *An ólann tú?* |
| No | *ní* + séimhiú | *Ní chuirim.* · *Ní ólaim.* |
| That | *go* + urú | *Deir sé go gcuireann sé…* · *go n-ólann* |
| That… not · Don't…? | *nach* + urú | *nach gcuireann* · *Nach n-ólann sé bainne?* |
| Where? | *cá* + urú | *Cá dtéann tú?* |
| What, who, when, how? | *a* + séimhiú | *Cad a dhéanann tú?* · *Conas a théann tú?* |
| Why? Which place? | *a* + urú | *Cén fáth a dtéann tú?* · *Cén áit a gcónaíonn tú?* |
| When, if | *nuair a, má* + séimhiú | *Nuair a bhíonn am saor agam…* · *Má théann tú…* |
| If … not | *mura* + urú | *Mura dtagann sé…* |
| *bí* right now | *tá · níl · an bhfuil · go bhfuil · nach bhfuil* | *An bhfuil tú sásta? Tá.* |

## How every lesson runs

Every lesson has the same seven steps, and each step goes out as its own message so feedback comes after every five answers.

1. **Recall (1 min).** Three quick items from earlier lessons, so old rules stay warm. Lesson 1 has a short Starter instead, since nothing comes before it.
2. **Model sentences (1 min).** Short source sentences with the target forms in bold. Read them aloud once. Unconnected sentences are listed one by one; a connected story is set as a paragraph.
3. **The rule (1 min).** One small table. Nothing else is new.
4. **Set A — Notice (5 items).** Spot or build the form with the rule in front of you.
5. **Set B — Apply (5 items).** Use the rule in sentences, usually as question / yes / no.
6. **Set C — Produce (3–5 items).** Translate or write your own sentences.
7. **Exit.** A confidence score from 1 to 5.

**Set D** is a spare set on the same rule. It runs only if a set scored 3/5 or lower, so a shaky rule gets five more goes before the next lesson.

**Mastery gate:** at most one item wrong in Set B and at most one in Set C before moving on (4/5, or 2/3 when a set has three items). Checkpoints (Lessons 7 and 15) need 80% overall.

**Feedback** comes in one table per set:

| # | What you wrote | Feedback | Correct version |
| --- | --- | --- | --- |
| 1 | *An n-ólann tú tae?* | 🔵 *an* leaves a vowel alone | *An ólann tú tae?* |
| 2 | *Ní chuirim.* | 🟢 🟣 séimhiú from *ní* | *Ní chuirim.* |
| 3 | *Glanann mé an chistin.* | 🔴 "I" is built into the verb | *Glanaim an chistin.* |
| 4 | *Ceannaionn sí bainne.* | 🟠 Missing fada | *Ceannaíonn sí bainne.* |

🟢 correct · 🔴 error · 🔵 mutation error · 🟠 typo or missing fada · 🟣 pattern to notice

**Item rules:** every item has a number so you can answer by number. Brackets give the root and the person, e.g. *(cuir, mé)*. Unusual words are glossed after the item; the answer is never in the question.

### Key terms

The same terms are used in all three tense courses (past, present and future).

| Term | Meaning | Example |
| --- | --- | --- |
| Root (*fréamh*) | The verb's dictionary form, which is also the order to one person | *cuir, glan, ól* |
| Broad / slender (*leathan / caol*) | A root whose last vowel is *a, o, u* is broad; *e, i* is slender. It decides how an ending is spelt | *glanann* (broad), *cuireann* (slender) |
| Séimhiú (lenition) | An *h* after the first consonant | *ní chuirim* |
| Urú (eclipsis) | A letter in front of the first consonant, or *n-* before a vowel | *an gcuireann, go n-ólann* |
| Particle | A small word in front of the verb that asks, denies or links | *an, ní, go, nach, cá* |
| Statement form | The form used when you simply tell | *téann, tá, deir* |
| Dependent form | The second form some irregular verbs use after a particle | *an bhfuil, níl, go bhfuil* |
| One-word form | A form with the person built into the ending | *glanaim, cuirimid* |
| Impersonal form (*briathar saor*) | Says something is done without saying who does it | *glantar, deirtear* |

## Part A — Building the verb (Lessons 1–4)

Part A answers one question: what does the verb look like when you simply say what someone does? The answer depends only on the root's last vowel and its number of syllables.

### Lesson 1 — Fréamh agus deireadh

**Goal:** say what someone does regularly, with a one-syllable verb.

**Starter** (no recall: this is where the present tense begins): read the model sentences aloud, then look at the end of each bold verb. Which two endings do you see, and what decides between them?

**Model sentences** (Aonad 4; Aonad 7):

- **Ólann** sé cupán caife gach maidin. (A4)
- **Cuireann** Seán airgead sa bhanc gach mí. (A4)
- **Éisteann** siad leis an raidió sa charr gach lá. (A4)
- **Seinneann** sí an fheadóg mhór. (A4)
- **Caitheann** Altan tréimhsí fada ar camchuairt thar lear. (A7)

*feadóg mhór* flute · *ar camchuairt* on tour · *thar lear* abroad

**The root** is the verb's dictionary form, which is also the order you give one person: *cuir!* (put!), *glan!* (clean!), *ól!* (drink!). Every present form in this course is built from the root.

**The rule:** look at the last vowel of the root. *a, o, u* (broad) → *-ann*. *e, i* (slender) → *-eann*. The start of the verb never changes in a statement. The form is the same for *tú, sé, sí, sibh* and *siad*: *glanann tú, glanann sí, glanann siad* ("I" and "we" are Lesson 2).

| Root | Present | Root | Present |
| --- | --- | --- | --- |
| glan | glanann sé | cuir | cuireann sé |
| ól | ólann sé | bris | briseann sé |
| fág | fágann sé | éist | éisteann sé |
| dún | dúnann sé | caith | caitheann sé |
| tóg | tógann sé | seinn | seinneann sé |

**Set A — Notice**

1–5. Find the five present-tense verbs in the model sentences and write each one's root.

**Set B — Apply** (write the full sentence in the present)

6. *(glan, sí)* an chistin gach oíche.
7. *(dún, siad)* an siopa ar a sé.
8. *(bris, sé)* a chuid spéaclaí go minic. — *spéaclaí* glasses
9. *(fág, Seán)* an teach ar a hocht.
10. *(caith, sibh)* an iomarca airgid. — *an iomarca* too much

**Set C — Produce** (translate)

11. She drinks tea every morning.
12. They close the office at five.
13. He listens to the news every evening. — *éist le*

**Set D — Spare**

14. *(tóg, sé)* an bus gach lá.
15. *(cuir, sí)* glaoch ar a máthair gach Domhnach.
16. *(ól, siad)* bainne.
17. *(seol, tú)* téacs chuig Liam gach maidin. — *seol* send
18. *(bain, sibh)* taitneamh as an rang. — *bain taitneamh as* enjoy

**Watch for:** the slender ending keeps the *e*: *cuireann*, never *cuirann*. And nothing is added to the front: *Glanann sí*, never *Ghlanann sí*.

### Lesson 2 — Mé agus muid

**Goal:** say what you do yourself, and what "we" do.

**Recall:** R1. *(glan, sí)* · R2. *(cuir, siad)* · R3. *(éist, sé)*

**Model sentences** (Aonad 4; Aonad 9; syllabus):

- **Fágaim** an teach go luath gach maidin. (A4)
- **Glanaim** an folcadán gach lá. (A9)
- **Caithim** seal ag siopadóireacht ar an Satharn. (A9)
- **Múchaim** gach fearas san oíche agus **bainim** an plug amach as an mballa. (A9 script)
- **Dúnaimid** / Dúnann muid an oifig gach oíche. (A4)
- **Tógaimid** sealanna an tsiopadóireacht a dhéanamh, uair sa tseachtain. (A9 script)
- **Casaimid** le chéile uair sa tseachtain. (Syl)

*folcadán* bath · *seal* a while · *fearas* appliance · *tógaimid sealanna* we take turns · *cas le chéile* meet up

**The rule:** "I" and "we" are built into the verb, with the same broad/slender choice as Lesson 1. Nothing comes after the one-word form. For "we", verb + *muid* is equally correct: *dúnaimid* or *dúnann muid*.

| Root | mé | muid | sé |
| --- | --- | --- | --- |
| glan | glanaim | glanaimid | glanann |
| fág | fágaim | fágaimid | fágann |
| dún | dúnaim | dúnaimid | dúnann |
| cuir | cuirim | cuirimid | cuireann |
| bris | brisim | brisimid | briseann |
| caith | caithim | caithimid | caitheann |

**Set A — Notice** (write the *mé* form and the one-word *muid* form)

1. ól
2. cuir
3. dún
4. éist
5. tóg

**Set B — Apply**

6. *(glan, mé)* mo sheomra gach Satharn.
7. *(fág, muid)* an teach ar a hocht.
8. *(caith, mé)* an iomarca ama ar an bhfón.
9. *(éist, muid)* le ceol sa charr.
10. *(buail, mé)* le Síle sa chathair gach Aoine. — *buail le* meet

**Set C — Produce** (translate)

11. I drink coffee every morning.
12. We close the door at night.
13. We meet every Tuesday. Write it both ways.

**Set D — Spare**

14. *(seinn, mé)* an giotár.
15. *(tóg, muid)* an traein gach lá.
16. *(rith, mé)* cúig chiliméadar gach Domhnach.
17. *(múch, muid)* na soilse.
18. *(díol, mé)* cácaí ag an margadh. — *díol* sell

**Watch for:** never add a pronoun after the one-word form. *Glanann mé, Glanaim mé* and *Glanaimid muid* are all wrong.

### Lesson 3 — Briathra dhá shiolla

**Goal:** use two-syllable verbs that end in *-aigh* or *-igh*, in every person.

**Recall:** R1. *(fág, mé)* · R2. *(cuir, muid)*, one word · R3. *(éist, sé)*

**Model sentences** (Aonad 4):

- **Ceannaíonn** sé bronntanas dom gach bliain.
- **Éirím** go luath gach maidin.
- **Imíonn** sí léi go Gaillimh gach lá.
- **Bailíonn** siad na leanaí ón scoil gach lá.
- **Tosaíonn** sé ag obair ar a naoi gach maidin.
- An gceannaíonn sibh ballraíocht gach bliain? **Ceannaímid.**

*imigh léi* go off · *bailigh* collect · *ballraíocht* membership

**The rule:** take off *-aigh* or *-igh*, then add the ending. *-aigh* → *-aíonn, -aím, -aímid*. *-igh* → *-íonn, -ím, -ímid*.

| Root | mé | sé | muid |
| --- | --- | --- | --- |
| ceannaigh | ceannaím | ceannaíonn | ceannaímid |
| tosaigh | tosaím | tosaíonn | tosaímid |
| ullmhaigh | ullmhaím | ullmhaíonn | ullmhaímid |
| éirigh | éirím | éiríonn | éirímid |
| imigh | imím | imíonn | imímid |
| bailigh | bailím | bailíonn | bailímid |

**Set A — Notice** (write the *sé* form)

1. ceannaigh
2. éirigh
3. ullmhaigh — *prepare*
4. bailigh
5. tosaigh

**Set B — Apply**

6. *(éirigh, mé)* ar a seacht.
7. *(ullmhaigh, sí)* an dinnéar gach tráthnóna.
8. *(tosaigh, muid)* ag obair ar a naoi.
9. *(ceannaigh, mé)* bainne gach lá.
10. *(imigh, siad)* abhaile ar a cúig.

**Set C — Produce** (translate; use one-word forms)

11. I get up early every morning.
12. She buys the newspaper every Sunday. — *nuachtán*
13. We collect the children from school.

**Set D — Spare**

14. *(bailigh, mé)* na leanaí ón scoil.
15. *(socraigh, sé)* na cruinnithe. — *socraigh* arrange
16. *(athraigh, muid)* an plean gach seachtain. — *athraigh* change
17. *(críochnaigh, mé)* ag obair ar a sé. — *críochnaigh* finish
18. *(gortaigh, sé)* a dhroim go minic. — *gortaigh* hurt; *droim* back

**Watch for:** the fada belongs to the ending: *ceannaíonn, éirím, bailímid*. Without it, *ceannaionn* is a spelling error.

### Lesson 4 — Giorrú agus -áil

**Goal:** handle verbs that shorten and verbs in *-áil*, then choose the right ending for any regular verb.

**Recall:** R1. *(ceannaigh, mé)* · R2. *(éirigh, muid)*, one word · R3. *(glan, siad)*

**Model sentences** (Aonad 4; Aonad 7):

- **Insíonn** sí an scéal céanna dom aon uair a bhuailim léi. (A4)
- **Osclaíonn** sé an siopa ar a hocht gach maidin. (A4)
- **Taispeánann** sé dom conas é a dhéanamh. (A4)
- **Marcálann** sí an obair bhaile gach seachtain. (A4)

**The rule:** two-syllable verbs ending in *-il, -in, -ir* or *-is* lose the vowel of their last syllable, then take the Lesson 3 endings. A few don't shorten: *foghlaim → foghlaimíonn*, *freastail → freastalaíonn*, *taistil → taistealaíonn*.

| Root | mé | sé | muid |
| --- | --- | --- | --- |
| imir | imrím | imríonn | imrímid |
| inis | insím | insíonn | insímid |
| oscail | osclaím | osclaíonn | osclaímid |
| labhair | labhraím | labhraíonn | labhraímid |
| freagair | freagraím | freagraíonn | freagraímid |
| codail | codlaím | codlaíonn | codlaímid |

Verbs in *-áil* and *-áin* take the one-syllable endings and drop the *i*: *sábháil → sábhálann, sábhálaim, sábhálaimid*; *taispeáin → taispeánann, taispeánaim*. *Tiomáin* stays slender: *tiomáineann, tiomáinim*.

**The five rules, checked in this order:**

- Two or more syllables, ends in *-(a)igh*? → *-aíonn / -íonn* (Lesson 3)
- Two syllables, ends in *-il, -in, -ir, -is*? → shorten, then *-aíonn / -íonn* (Lesson 4)
- Ends in *-áil* or *-áin*? → *-álann, -ánann* (Lesson 4)
- One syllable, broad? → *-ann, -aim, -aimid* (Lessons 1–2)
- One syllable, slender? → *-eann, -im, -imid* (Lessons 1–2)

## Part B — Asking, denying, reporting (Lessons 5–7)

Part B adds the little words in front of the verb. There is only one family of them: *an, go, nach* and *cá* take urú, *ní* takes séimhiú, and the ending never changes.

### Lesson 5 — Ceist agus diúltú

**Goal:** ask and say "no" with any regular verb, whatever its first letter.

**Recall:** R1. *(glan, muid)*, one word · R2. *(imir, mé)* · R3. *(sábháil, sé)*

**Model sentences** (Aonad 4; Aonad 9):

- **An gcuireann** tú glaoch ar Mháire gach Luan? **Cuirim.** (A4)
- **An ndúnann** tú an oifig ag am lóin? **Ní dhúnaim.** (A4)
- **An gceannaíonn** tú bainne gach lá? **Ní cheannaím** bainne úr gach lá. (A9)
- **An ólann** tú caife ag a haon déag gach lá? (A4)
- **An ullmhaíonn** tú béile? **Ullmhaím. / Ní ullmhaím.** (A9)
- **An bhféachann** tú ar an teilifís gach oíche? **Féachaim. / Ní fhéachaim.** (A4)

*úr* fresh · *ag a haon déag* at eleven · *béile* meal

**The rule:** to ask, put *an* in front and add urú. To say no, put *ní* in front and add séimhiú. A vowel takes nothing after either: no *n-*, no *h*. Short answers repeat the verb: a *tú* question gets the *mé* form (*Cuirim. / Ní chuirim.*); a *sé* question gets verb + *sé* (*Cuireann sé.*); a *sibh* question gets the "we" form (*Ceannaímid.*).

| First letter | After *an* (urú) | After *ní* (séimhiú) |
| --- | --- | --- |
| b | *An mbuaileann tú?* | *Ní bhuailim.* |
| c | *An gcuireann tú?* | *Ní chuirim.* |
| d | *An ndúnann tú?* | *Ní dhúnaim.* |
| f | *An bhféachann tú?* | *Ní fhéachaim.* |
| g | *An nglanann tú?* | *Ní ghlanaim.* |
| p, t | *An bpósann…? · An dtógann tú?* | *Ní phósann. · Ní thógaim.* |
| vowel | *An ólann tú?* (no change) | *Ní ólaim.* (no change) |
| m, s + vowel | *An múchann tú? · An seinneann tú?* (no urú) | *Ní mhúchaim. · Ní sheinnim.* |
| l, n, r, sc, sm, sp, st | *An ritheann tú?* (no urú) | *Ní rithim.* (no séimhiú) |

Urú only works on b, c, d, f, g, p, t. Séimhiú skips l, n, r, sc, sm, sp, st: Lazy Nuns Rarely Stop to Smile, or Speak about iScream.

## Part C — Irregular verbs (Lessons 8–11)

The present is the kindest tense for irregular verbs. *Bí* has two presents (*tá* and *bíonn*), three verbs take a new root, and everything else uses the endings and little words from Parts A and B.

**Goal:** use *tá* for what is true now, with its own question and negative.

**Recall:** R1. *(ceannaigh, mé)* · R2. Question, yes and no for *(fan, tú)* · R3. Deir sé \_\_\_ *(ól)* sé caife.

**Model sentences** (Aonad 1; Aonad 4; syllabus):

### Lesson 12 — Focail cheiste

**Goal:** ask what, who, when, how, where and why about the present.

**Recall:** R1. *(téigh, mé)* · R2. Make negative: *Deirim é.* · R3. An \_\_\_ *(bí)* tú sa bhaile anois?

**Model sentences** (Aonad 4; Aonad 9; syllabus; Caighdeán):

- **Cad a dhéanann** tú nuair a bhíonn am saor agat? (Syl)
- **Cé a dhéanann** an dinnéar gach lá? (A9)
- **Cén t-am a thosaíonn** tú ag obair ar maidin? (A4)
- **Conas a théann** tú go dtí an obair? (A4)
- **Cá dtéann** tú gach tráthnóna? (A9)
- **Cá háit a mbíonn** na ranganna sin ar siúl? (Caighdeán 11G)
- **Cén fáth a gcuireann** tú do chuid ama amú mar sin? (Caighdeán 11G)

*am saor* free time · *ar siúl* on, happening · *ag cur ama amú* wasting time

**The rule:** most question words take *a* + séimhiú. *Cá* takes urú directly. Words about place, reason and manner (*cén áit, cá háit, cén fáth, cén chaoi*) take *a* + urú, and a vowel gets *n-*.

| Question word | Then | Example |
| --- | --- | --- |
| *Cad a / Céard a* | séimhiú | *Cad a dhéanann tú?* |
| *Cé a* | séimhiú | *Cé a ghlanann an chistin?* |
| *Cén t-am a / Cathain a* | séimhiú | *Cén t-am a éiríonn tú?* (vowel: no change) |
| *Conas a* | séimhiú | *Conas a théann tú ag obair?* |
| *Cá* | urú | *Cá dtéann tú?* · *Cá bhfuil sé?* |
| *Cén áit a / Cá háit a* | urú | *Cén áit a gcónaíonn tú?* |
| *Cén fáth a* | urú | *Cén fáth a dtéann tú ansin?* |

With *tá*: *Cad atá ar siúl? Cé atá ann?* (*a* + *tá* = *atá*), but *Cá bhfuil …? Cén fáth a bhfuil …?* And *deir* keeps its plain *d*: *Cad a deir sí?*

**Set A — Notice** (write the verb)

3. Cén t-am a \_\_\_ *(fág)* tú an teach?

**Set C — Produce** (translate)

**Watch for:** *Cad a dhéanann* (séimhiú) but *Cá dtéann* (urú). If you hear *a* before the verb, check which family the question word belongs to.

### Lesson 13 — Nuair a, má agus mura

**Goal:** talk about routines and conditions: when this happens, if that happens, if it doesn't.

**Recall:** R1. Cad a \_\_\_ *(déan)* tú? · R2. Cá \_\_\_ *(téigh)* tú? · R3. Cén fáth a \_\_\_ *(bí)* tú anseo? (now)

**Model sentences** (syllabus; Aonad 9; Aonad 11 script; Caighdeán):

- **Nuair a bhíonn** aimsir mhaith ann, téim ag snámh san fharraige. (Syl)
- **Nuair a bhíonn** an aimsir olc, tugaim síob chuig an scoil do na páistí. (Syl)
- Téimid go dtí ceolchoirm sa chathair **nuair is féidir linn**. (A9)
- **Má bhím** ag rith rófhada, cuireann mo mhurnán isteach orm. (A11 script)
- Déanfaidh mé um thráthnóna é **má bhíonn** deis agam. (Caighdeán 5.1.9)

*murnán* ankle · *cuir isteach ar* bother · *um thráthnóna* this evening · *deis* chance

**The rule:** *nuair a* (when) and *má* (if) take séimhiú, like a statement with *a* in front. *Mura* (if … not) takes urú. After *má*, use the present (*má bhíonn*) even when you mean the future: never *má beidh*.

| Word | Then | Example |
| --- | --- | --- |
| *nuair a* | séimhiú | *Nuair a bhíonn sé fuar, caithim cóta.* · *nuair a éirím* (vowel: no change) |
| *má* | séimhiú | *Má théann tú ann, …* · *Má fhaighim an t-am, …* |
| *má* + *tá* | no change | *Má tá tú tuirseach, …* |
| *má* + *deir* | no change | *Má deir sé é, creidim é.* |
| *mura* | urú | *Mura dtagann sé, …* · *mura n-itheann tú* · *mura bhfuil* |

### Lesson 14 — An briathar saor

**Goal:** understand and use the impersonal present: "one does", "it is done".

**Recall:** R1. Nuair a \_\_\_ *(bí)* an aimsir go maith, … · R2. Mura \_\_\_ *(tar)* sé, … · R3. Cá \_\_\_ *(téigh)* sé?

**Model sentences** (Caighdeán; syllabus):

- **Labhraítear** an Ghearmáinis san Ostair. (Caighdeán 1.1.5)
- **Eagraítear** comóradh uair sa bhliain. (Caighdeán 1.1.5)

**The rule:** add *-tar* (broad), *-tear* (slender), *-aítear* or *-ítear* (two syllables). No person comes after it. A root ending in *t* or *th* keeps only one *t*: *caith → caitear, ith → itear*. Questions and negatives follow Lesson 5: *An ndíoltar? Ní dhíoltar.*

| ceannaigh | *ceannaítear* | faigh | *faightear* |
| labhair | *labhraítear* | tabhair | *tugtar* |
| caith | *caitear* | téigh | *téitear* |
