# Irish Tense Courses

Self-study mini-courses in the three main Irish verb tenses, aligned with the TEG B1 syllabus. Each course is designed to be run by an AI chat assistant acting as a tutor: every file contains the full syllabus, the tutor instructions, the exercises and an answer key.

## Courses

| File | Course | Lessons |
| --- | --- | --- |
| `An Aimsir Chaite Past Tense Mini-Course.md` | An Aimsir Chaite (past tense) | 17 |
| `An Aimsir Láithreach Present Tense Mini-Course.md` | An Aimsir Láithreach (present tense) | 15 |
| `An Aimsir Fháistineach Future Tense Mini-Course.md` | An Aimsir Fháistineach (future tense) | 13 |

Each lesson takes 5–10 minutes and follows the same steps: Recall, Model sentences, The rule, then exercise Sets A–C (with a spare Set D), feedback and a confidence score.

## How to use

1. Start a new chat with an AI assistant and upload one course file (or paste it in).
2. Type: *Be my tutor for this course. Start Lesson 1.*
3. Answer each set by item number, one set per message.
4. Copy the tutor's progress line into the Progress tracker at the end of the file. Paste the tracker into any new chat to pick up where you left off.

Learners need A2–B1 vocabulary; no prior knowledge of the tense is assumed.
